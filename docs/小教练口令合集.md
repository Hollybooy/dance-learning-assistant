# 小教练口令合集

> 对应版本：2026-11-24（小教练 2.0）
> 相关档案：`backend/app/services/voice_assistant.py`（听）、`js/app.js`（说与执行）

---

## 一、怎么跟它说话

1. 打开任意页面后，前端会连上 `/ws/voice`，浏览器弹一次麦克风授权；授权后状态从 `loading` 变 `listening`。
2. 每句话**必须带唤醒词「小教练」**，例如「小教练，暂停」；只说「暂停」不会触发，避免聊天时误操作。
3. 说完等一句反馈：能识别成指令的会立刻执行并回一句；识别不出的会回「没听清」。
4. 关掉页面即停止录音，不会后台常驻。

排查顺序（没反应时）：

| 现象 | 先看这里 |
|---|---|
| 页面右下角麦克风图标灰着 | 设置里「语音指令（唤醒词：小教练）」被关了 |
| 状态一直是 `loading` | 首次加载 Whisper 模型，等 5–15 秒 |
| 状态 `error` | 没有麦克风 / 浏览器拒绝授权 / `sounddevice` 没装 |
| 说了没反应，文字提示也不出 | 检查是否带了「小教练」，或环境太吵（VAD 阈值） |
| 复杂句理解错 | Ollama 没启动时会退回规则匹配，只认固定说法；启动后能理解「我想看那个古风燃脂」 |

## 二、口令表

### 1. 播放控制

| 口令 | 同义说法 | 效果 |
|---|---|---|
| 小教练，暂停 | 停一下、先停、别放 | 教学视频暂停，录制不受影响 |
| 小教练，继续播放 | 继续、接着、恢复 | 从暂停处继续 |
| 小教练，下一片段 | 下一段、换一段 | 切到下一个切片并自动播放 |
| 小教练，上一片段 | 上一段、回上一段 | 切回上一个切片 |
| 小教练，重播本段 | 再来一遍、重放 | 当前切片从头播放 |
| 小教练，从头重新播放 | 重新播放、从头开始播、从头来 | 回到第 1 段，从课程开头重播 |
| 小教练，自动播放 | 自动连播、改成自动 | 本段播完自动进入下一段 |
| 小教练，手动播放 | 手动连播、改成手动、别自动了 | 播完停在原地等你切换 |
| 小教练，切换播放模式 | 换个播放模式 | 在自动/手动之间切换，并播报当前模式 |
| 小教练，开始跟练 | 开始练习、进入跟练 | 从课程详情页进入跟练页 |
| 小教练，播放〈课程名〉 | 我想看〈课程名〉、打开〈课程名〉 | 模糊匹配课程并直接进入 |

### 2. 画面与速度

| 口令 | 同义说法 | 效果 |
|---|---|---|
| 小教练，显示骨架 | 打开骨架、要骨架 | 显示教练骨架线 |
| 小教练，隐藏骨架 | 关掉骨架、不要骨架、把骨架隐藏 | 隐藏骨架线 |
| 小教练，显示阴影 | 打开阴影、显示轮廓 | 显示人体轮廓阴影 |
| 小教练，隐藏阴影 | 关掉阴影、隐藏轮廓、把轮廓关了 | 隐藏轮廓阴影 |
| 小教练，快一点 | 加速、快点、快些 | 播放倍速升一档（0.75 → 0.9 → 1 → 1.25 → 1.5） |
| 小教练，慢一点 | 减速、慢点、慢些 | 播放倍速降一档 |
| 小教练，恢复原速 | 正常速度、正常倍速、恢复速度 | 回到 1.0 倍速 |

### 3. 录制与收藏

| 口令 | 同义说法 | 效果 |
|---|---|---|
| 小教练，开始录制 | 开始录像、录一段 | 触发录制倒计时，录制结束后自动保存并打开回放 |
| 小教练，结束录制 | 停止录制、停止录像、别录了 | 结束录制并保存 |
| 小教练，收藏这个课程 | 收藏 | 加入 Stars（再说一次取消） |

### 4. 查询与设置

| 口令 | 同义说法 | 效果 |
|---|---|---|
| 小教练，现在进度怎么样 | 到哪了、第几段了、多少分、准确率 | 播报「第 2 段，共 5 段，当前重合 87%」 |
| 小教练，安静一点 | 别说话、闭嘴、关闭语音、不用说话 | 关掉语音播报（只留文字气泡） |
| 小教练，可以说话了 | 打开语音、恢复语音、说话吧 | 恢复语音播报 |
| 小教练，你会什么 | 帮助、能做什么、指令、怎么用 | 一口气播报可用指令清单 |

## 三、它自己会说什么

| 时机 | 播报内容 |
|---|---|
| 进入/切换片段 | 「第 2 段，共 5 段，跟好老师的节奏」 |
| 本段播放完毕 | 「这一段完成，选下一段继续」 |
| 开始录制 | 「开始录制，我盯着你的动作」 |
| 录制保存成功 | 「练习已保存，一起去回放看看」 |
| 轮廓重合首次 ≥ 90% | 「轮廓几乎重合了，保持住！」（掉回 72% 以下才会再次触发） |
| 动作偏差（实时分析） | 按部位给具体建议，如「右臂抬高一点，跟上老师」；同一部位 4 秒内不重复 |

## 四、声音设置

「个人主页 → 系统设置」里有两项：

| 设置项 | 默认 | 说明 |
|---|---|---|
| 小教练音色 | 自动 | 自动时按优先级挑：Edge Natural 在线音 > 晓晓 > 晓伊 > 云希 > 婷婷 > 美佳 > Google 中文 > 其他中文音；Huihui、Kangkang 这类机械音只在没有别的可选时才用 |
| 小教练语速 | 正常 | 慢 0.85 / 正常 0.98 / 快 1.12 |

- 切换音色会立刻念一句试听，选择保存在浏览器本地。
- 声音走浏览器自带的 `speechSynthesis`，不联网、不占 CPU；但 **Edge 的 Natural 语音需要联网**。
- Chrome 在 Windows 上通常只暴露 Huihui 等老式音色，想要自然的女声建议用 Edge 打开页面。
- 系统音色列表是异步加载的，第一次打开设置面板如果显示「未检测到中文音色」，等一秒会自动刷新。

## 五、给开发看的：指令是怎么走的

```
麦克风 → 能量 VAD 切句 → faster-whisper（CPU int8，中文）→ 必须含「小教练」
      → parse_rule_intent()（关键词，<1ms）
      → 没命中再交 Ollama Qwen2.5-1.5B 输出 JSON
      → /ws/voice 推 {"type":"command","action":"...","reply":"..."}
      → 前端 runVoiceCommand() 执行并播报
```

新增一条指令要改三处：

1. `backend/app/services/voice_assistant.py`：`parse_rule_intent` 加关键词、`_ACTION_REPLY` 加回复、Ollama system prompt 的 action 列表加值、`_INITIAL_PROMPT` 加词；
2. `js/app.js` 的 `handleVoiceCommand`：加一个分支执行动作；
3. 自己播报的分支 `return 'silent'`，其余留给 `_ACTION_REPLY` 统一播报，避免说两遍。

`action` 全量清单：`play_video`、`pause`、`resume`、`next_segment`、`prev_segment`、`restart_segment`、`restart_video`、`start_practice`、`autoplay_on`、`autoplay_off`、`toggle_autoplay`、`skeleton_on`、`skeleton_off`、`shadow_on`、`shadow_off`、`speed_up`、`speed_down`、`speed_normal`、`record_start`、`record_stop`、`report_progress`、`mute_coach`、`unmute_coach`、`favorite`、`help`、`none`。
