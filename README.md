# DanceMate · 舞蹈学习助手（前端）

根据舞蹈学习者提供的教学视频辅助学习：将上传/搜索到的教学视频按固定时间间隔切分成片段，
配合摄像头记录跳舞情况，支持跟练学习与纠错回放。

> 当前仅实现前端页面（纯 HTML/CSS/JS，无构建依赖），后端暂未开发。

## 页面说明（对应设计稿）

| 视图 | 设计稿 | 功能 |
|------|--------|------|
| 视频选择 selecting | 图1 | 聊天历史记录框、轮播图（视频按固定时间间隔切片预览）、搜索教学视频、手动上传视频文件 |
| 跟练学习 learning | 图2 | 左：教学视频当前片段（可向左切换上一片段）；右：摄像头实时画面（可向右切换下一片段）；底部轮播图与图1一致 |
| 纠错回放 error correct | 图3 | 左：教学视频片段列表（左右切换）；右：摄像头画面回放（暂做一个按钮）；底部轮播图与图1一致 |

## 运行

```powershell
cd dance-learning-assistant
python -m http.server 8000
# 浏览器打开 http://localhost:8000
```

> 摄像头 API（getUserMedia）要求 `localhost` 或 HTTPS 环境访问。

## 使用流程

1. 在"视频选择"页手动上传本地教学视频；
2. 应用自动按 `js/app.js` 中的 `SEGMENT_SECONDS`（默认 10 秒）切成片段，轮播图展示所有片段；
3. 点击任意片段进入"跟练学习"页，左侧播放教学片段、右侧显示摄像头实时画面；
4. 在"纠错回放"页查看摄像头画面回放（后端接入后为录像回放）。
